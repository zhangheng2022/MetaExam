# 代码审查问题修复与回归（2026-11-26）

本次修复三个已复现问题，不新增数据库迁移，不改变 V1～V10 的 SQL 或授权文件格式。

## 修复内容

1. **安装数据目录 ACL**：原来的 `/inheritance:r /grant:r` 会保留预建目录中其他身份的显式 ACE。现在首次安装只接受不存在或空的数据目录，使用新的受保护 DACL 替换旧权限，仅保留 SYSTEM／Administrators 完全控制，并将所有者设为 Administrators。随后沿用现有服务分目录授权及普通用户读取公开配置的权限。拒绝非空目录、文件、驱动器根目录、目录联接及含联接的祖先路径；拒绝阶段不向该目录写日志。已有数据库继续使用维护升级流程，不重新初始化。
2. **并发入场阻塞**：Windows 硬件采集从同步子进程改为异步，只合并同一进程中尚未结束的采集，完成或失败后均不缓存。发布／入场先采集设备信息，再开启业务事务；事务内仍核对安装实例、锁定最新授权、完全本地验签并判断时间、权益和容量。已合法入场的重复请求不依赖新的硬件采集或当前授权。
3. **冻结作答说明缺失**：答卷详情从入场所引用的 `paper_versions` 读取 instructions；考生页面在题号导航前显示作答说明。按纯文本保留换行，不解析 HTML；说明为空时不显示空标题。
