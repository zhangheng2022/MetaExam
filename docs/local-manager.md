# 本地管理器改版

日期：2026-11-26。

## 交付

本地管理器使用共享 UI 包的 `LocalManager`，Electron renderer 只挂载主题和受限 bridge。移除单菜单侧栏及常驻初始化成功面板，分为首次设置、一次性成功反馈和日常概览。默认窗口 1000 × 720，最小 380 × 600；系统服务与软件授权在窄窗口下自动改为单列。

系统与初始化状态并行读取，每 15 秒刷新；同一轮请求未完成或初始化正在提交时不发起重复检查。初始化提交使旧检查结果失效，已完成初始化的状态不能被旧响应重开。检查失败保留并标注上次数据；数据库不可用或初始化状态未知时不展示初始化表单。未激活或授权过期不阻止管理员创建和业务登录入口。

新增 `business:copy-address`，仅复制主进程生成的本机登录地址。它与 `business:open` 共用地址生成函数、现有发送 frame/页面来源校验；无任意地址、命令或文件参数。保持 sandbox、contextIsolation、禁用 Node 集成与既有 CSP。未改初始化令牌、数据库、本地验签或服务安装逻辑。

## 本机验证

`./tools/run.ps1 test:desktop` 包括：

- `desktop-setup.mts`：独立数据库、真实 API 和 Electron；普通权限初始化被拒绝，不生成令牌或账号，退出客户端后 API 仍可用。
- `desktop-manager.mjs`：真实 Electron、主进程 IPC 与可控本机 HTTP 测试服务；覆盖初始加载与失败、数据库故障、恢复初始化、令牌过期反馈、一次性成功页面、旧状态不能重开初始化、已初始化直接进入概览。
- 覆盖未激活、有效授权、到期、Worker 离线、断连旧数据和恢复；固定业务地址的打开与复制、外部窗口 IPC 拒绝、沙箱配置、关闭客户端后测试服务存活。
- 检查默认窗口内容可见、380px 窄窗口和 150% Electron 内容缩放无横向溢出；截图与结果写入忽略提交的 `artifacts/local-manager`。
- 测试替换系统浏览器打开及剪贴板写入，以核对地址且不改变用户剪贴板；初始化成功仅模拟 UI 返回结果，不提升本机权限。

本次 build、typecheck、lint、format:check、test（27 项）、test:ui、test:desktop 和 test:integration 已通过；`test:dev --startup-only` 验证统一启动入口、实际 IPC、默认蓝色主题以及客户端关闭后 API/Worker/Vite 继续运行。桌面冒烟检查改为等待首次状态加载后的主按钮渲染，再检查主题，避免把骨架屏阶段误判为启动失败。

## 独立环境回归

本次没有重建安装包或变更安装器。本机模拟成功反馈不代表已重新验收提升权限初始化。

- 安装新版客户端后，以管理员身份完成真实首次设置；普通权限无法读取初始化令牌。
- 已初始化机器以普通权限打开，直接进入概览；业务登录地址符合 HTTP 开发／HTTPS 部署配置。
- 检查实际系统默认浏览器打开和复制地址；HTTPS 信任沿用部署验收要求。
- 在 Windows 显示缩放 125%、150% 下检查文字、按钮和滚动；Electron 内容缩放测试不能替代实际 DPI 验收。
- 关闭客户端后 API/Worker 服务继续运行。

上述项目保持待回归，不重复宣称此前独立环境验收覆盖本次改版。
