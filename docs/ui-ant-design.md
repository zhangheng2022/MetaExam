# Ant Design 界面交付

日期：2026-11-25。依据用户指定的 [Ant Design design.md](https://ant.design/design.md) 实现既有业务界面；组件接口对照已安装的 6.7.2 CLI 查询，不升级依赖。

## 实现范围

- 登录页：品牌、居中表单、提交反馈、系统未初始化指引与异常重试。
- 账号中心：共享侧栏、顶部栏、面包屑、个人资料、安全分区、真实管理概览。
- 改密页：影响说明、原密码/新密码/确认密码、返回入口；改密后仍撤销全部会话。
- 手机端：抽屉导航、单列内容、长名称处理和局部状态反馈。
- 共享主题：默认蓝色、默认语义色与控件尺寸、Token 驱动的业务背景及边框；Electron 共享身份表单同步应用。

本次不新增账号或教学组织管理接口，不显示尚未实现的菜单，不修改本地验签与身份权限。未重新生成内部 EXE；现有安装包不包含此次源码界面更新。

## 验证

构建、类型检查、ESLint、Ant Design CLI 检查、运行状态页回归，以及独立测试库中的浏览器身份流程和 Electron 初始化回归通过。浏览器检查覆盖手机导航、默认蓝色、横向溢出、真实登录/刷新/概览/改密/退出、503 恢复及会话失效，并检查无 CSP 违规和外部资源请求。

根目录 format:check 因遍历受限的 .local/bootstrap 返回 EPERM；未修改令牌 ACL。改为显式指定源码、测试、配置和文档目录执行 Prettier 检查。机械设计检查提示原运行状态页字号与旧设计文档差异；新增业务字号及默认文本色已记录到 DESIGN.md，不据此宣称完整无障碍合规。构建仍有既有的大 chunk 和桌面 Vite 配置兼容性提示。
