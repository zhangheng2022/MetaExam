# Web 界面优化（0.1.19）

2026-11-27：仅优化 Web 视觉与布局，保留 Ant Design 默认蓝色、14px 正文和原生组件。客户版本提升至 0.1.19，供应方保持 0.1.6；数据库保持 V10，无业务 API、权限、依赖及迁移变更。

## 变更

- 登录品牌与表单居中，统一浅色背景、卡片密度与留白。
- 导航按考试教学、基础管理、我的账号分组；保持原权限及强制改密限制，窄屏使用原抽屉。
- 统一列表筛选区、表格行间距、统计区块及编辑抽屉操作顺序。
- 作答页宽屏题目在左、答题卡在右；窄屏先显示考试及剩余时间。保留自动保存、断线说明、保存状态及交卷确认。
- Web 组件 Token 通过独立 WebSurface 配置，管理器及供应方不使用该入口。

## 本机验证

真实浏览器使用隔离数据库，未修改开发账号。已通过登录、账号管理、题库、组卷、考试发布、考生作答、阅卷、成绩统计及 Excel 下载的现有浏览器测试，以及 test:ui、test:form-experience、test:desktop。涵盖桌面／窄屏、角色限制、未保存保护、保存失败、断线重试、交卷及结果页面；实际截图保存在忽略提交的 artifacts 目录。

build、typecheck、零警告 lint、format:check、package:win、test:package 均通过。包验证包括固定签名检查、普通权限拒绝、隔离载荷启动，以及实际打包 Electron 的诊断检查／导出／取消、断网／503、脱敏、拒绝覆盖、外部 frame 拒绝和窄屏布局。Ant Design CLI 检查零问题，graphify update 已完成。
