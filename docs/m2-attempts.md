# M2 第五批：考生入场与答题会话

日期：2026-11-25。交付“已发布考试 → 学生入场 → 五类题型作答 → 自动保存／刷新恢复 → 手动交卷或到时收卷 → 回执”。数据库 V9。沿用 [考试发布](m2-exams.md) 和冻结试卷，不实现阅卷、成绩、补考、延时、强制停考、防作弊或教师监考台。

## 启动与人工验收

1. 运行 `./tools/run.ps1 dev`。按上一批步骤准备学生、课程、班级、题库、冻结试卷及已发布考试；发布和新入场均需要含 exam.core 的有效本地授权。不要改动生产数据库时间字段来提前开考。
2. 学生先完成首次改密，进入“我的考试”。未到开考时间不能入场；进入考试窗口后刷新列表，点击进入并确认。教师和管理员角色本身不具备考生权限。
3. 入场后检查考试名称、截止时间、倒计时与题号。依次验证单选、多选、判断、填空和简答；判断的“错误”是有效答案。题干与图片可见，标准答案和解析不可见。已填写数量表示存在非空作答，部分填空也计入，不代表答对或填完所有空。
4. 输入后约 800ms 自动保存；只有“已保存”表示服务器确认。手动保存、切换题号和上下题均可验证答案保留。刷新页面和重启 API 后恢复已保存内容。
5. 在答题页临时中断局域网连接：输入保留在当前页面内存，显示失败并允许重试。恢复网络后保存。**未确认保存的输入不写 localStorage，刷新、离开或关闭页面可能丢失；此功能不是断网独立考试。**换题和交卷会先保存，普通导航不承诺保存；浏览器关闭／刷新在存在未保存输入时提示。
6. 同一账号打开两个页面，先在一页保存，再在另一页修改同题，应提示冲突。重新读取前确认放弃本页修改；不允许静默覆盖。不同题的保存通过整体答卷版本保护最终交卷。
7. 使用低容量测试授权让多名学生同时进入，超过容量应被拒绝。关闭页面不释放名额；已入场学生重新进入返回同一份答卷。一人一场只允许一次，一人同时只能参与一场。
8. 合法入场后软件授权到期，已有答卷仍可继续保存和交卷；未入场者被拒绝。账号停用、角色撤销或登录失效仍影响身份访问；不会因授权续期获得额外答题时间。
9. 点击交卷，核对已填写数量并确认，显示回执。刷新／重复交卷返回同一结果，不能再读取题目、图片或修改答案，也不能重考。新入场者此时可使用释放的名额。
10. 准备短时考试，等待服务器截止，验证自动收卷和回执。截止后只能封存之前保存到服务器的答案；断网期间未上传的内容不补交。Worker 重启后补收过期答卷，读取／保存路径也检查截止时间。

## 规则、持久化与权限

- 新入场在数据库事务内串行化权限／名单检查与名额分配，复用完全本地 Ed25519 验签。记录真实入场时间、固定试卷版本、授权 ID／序号和授权有效期。发布时的授权摘要不能替代入场凭据，不增加任何远程授权依赖。
- 全局名额统计有效的 active 答卷；数据库唯一约束保护一人一场一次和同人同时一场。已合法入场的答卷使用可信授权记录继续答题，后续当前软件授权失效不会中断它。
- 截止为 `min(入场时间 + 答题分钟数, 考试结束时间)`。服务器负责裁决；浏览器倒计时基于服务器返回时间和单调计时，约每 10 秒校准。系统仍依赖服务器本地时钟，不承诺抵御管理员修改系统时间。
- Worker 约每秒扫描到期答卷，长任务或停机会延后扫描；接口同时检查截止，数据库答案触发器拒绝截止后写入。恢复后收卷时间记录为原截止时间，不因停机补时。
- 每题使用 revision 与 mutationId。相同 mutationId／相同答案可安全重试，不同内容复用同一 ID 或旧 revision 返回 409。交卷使用整体 revision，防止另一页面保存后被旧状态交卷。
- 学生接口只返回本人答卷、显式挑选的题干、选项／填空 ID、图片和本人已保存输入，不返回标准答案、解析、填空评分标记或教师元数据。题图必须属于该冻结试卷且答卷仍有效，通过专用鉴权接口读取并验证文件摘要。
- V9 新增 exam_attempts、attempt_answers；外键、唯一索引和触发器保护身份、固定参数及交卷后不可修改。运行身份只有必要 DML，无 DDL；迁移由维护身份执行。审计只记录入场／提交／超时及对象标识，不复制答案正文。
- 本机维护停止接口在存在有效答卷或本进程入场请求时拒绝停止；单 API 进程内设置停止闸门。这不是多 API 实例的分布式停机协议，也不能阻止操作系统直接杀进程。关闭 Electron 不影响 API／Worker。

## 接口

统一前缀 `/api/v1`。要求学生角色、exams.self、已完成强制改密的 Cookie 会话；写请求执行 CSRF 校验和严格输入校验。错误格式沿用 `{code,message,requestId}`。

| 方法与路径                              | 行为                                                  |
| --------------------------------------- | ----------------------------------------------------- |
| POST `/my-exams/:examId/start`          | 无业务字段；本地验签并分配名额，重复入场返回原答卷 ID |
| GET `/attempts/:id`                     | 本人答卷状态、截止、版本、题号及填写状态              |
| GET `/attempts/:id/questions/:position` | 逐题安全内容、本人答案和答案 revision                 |
| PUT `/attempts/:id/questions/:position` | revision、mutationId、answer；保存或幂等重试          |
| POST `/attempts/:id/submit`             | 校验整体 revision 后交卷；已关闭时幂等返回            |
| GET `/attempts/:id/images/:file`        | 本人有效答卷引用的 PNG 图片，no-store                 |
