# M2 第一批：题库与不可变版本

日期：2026-11-25。本文记录第一批题库基础交付；其后的 Excel 导入和题目图片已在 [第二批](m2-imports.md) 实现，当前数据库为 V6。下文 V5、包哈希与验收结果保留为第一批历史记录。M2 整体尚未完成，组卷、考试发布和正式考试入场仍在后续批次。

## 已实现范围

- 公共题库与个人题库：创建、修改名称／说明、归档／恢复、分页搜索。
- 单选、多选、判断、填空、简答五类题目：录入、编辑、预览、归档／恢复。
- 按题干、题型、难度、标签、知识点及归档状态检索，筛选和分页保存在 URL。
- 每次编辑新增版本，保留原题干、选项、答案、解析、难度、标签与知识点；历史分页查询，时间显示北京时间。
- 服务端逐对象鉴权、强制改密限制、revision 冲突、原子审计及旧版本防修改。
- Ant Design 默认蓝色，沿用共享导航、列表与编辑抽屉；题库页面延迟加载，资源随本地安装包交付。

## 权限与规则

| 身份       | 可读                                                                   | 可写                                         |
| ---------- | ---------------------------------------------------------------------- | -------------------------------------------- |
| 管理员     | 所有题库及历史，包括停用课程                                           | 启用课程下所有题库；归档题库须先恢复         |
| 教师       | 启用的任课课程下公共题库和本人个人题库，且至少有一个启用班级的授课关系 | 本人个人题库；不能创建公共题库或修改公共题目 |
| 学生／匿名 | 无题库权限                                                             | 无                                           |

“公共”仅指课程内教师可读。其他教师的个人题库、跨课程题库和伪造的题目归属均返回 404；学生访问返回 403，匿名返回 401。管理员可管理个人题库，创建时界面明确说明这一点。

题库课程、创建人及可见范围创建后固定。解除授课关系、停用课程／班级或移除教师角色后，下一次请求重新计算权限。管理写操作与账号、授课维护使用同一事务咨询锁，锁内复核权限。账号停用和强制改密沿用现有认证限制。

题目只支持纯文本，React 按文本显示，不解析 HTML，不下载外部资源。题干和解析各最多 8000 字符，单题 JSON 最多 48000 UTF-8 字节。选项 2～8 个，内容和标识唯一；单选恰好一个答案，多选至少两个答案，答案须引用本题选项的稳定 UUID。后续评分依据版本内 ID，不依赖展示字母或顺序。

填空以 `[[blank]]` 标记，数量须与答案配置一致；最多 20 空，每空最多 10 个候选答案。分别保存大小写和首尾空白处理规则；保留候选答案原始首尾空白。简答保存参考答案，后续人工评分。本批未执行评分。

难度 1～5；标签和知识点各最多 10 个，随题目版本保存。本批没有知识点树、共享标签字典、题目转移／复制或批量导入。无物理删除入口；归档保留历史。归档／恢复改变 revision，不复制内容版本。后续试卷应引用固定 `question_versions.id`，不能只引用题目当前版本。

## 数据迁移与启动

V1～V4 原始 SQL 与校验和保持不变。V5 新建 `question_banks`、`questions`、`question_versions`，增加 `questions.use` 权限给管理员和教师。

题目与当前版本之间使用延迟外键，二者在同一事务提交；`question_id + version` 唯一。触发器拒绝 UPDATE／DELETE 历史版本，运行角色只获得版本表 SELECT／INSERT，不获得 DDL／TRUNCATE。Drizzle 声明同步更新，延迟外键和触发器仍以 SQL 迁移为准。

本机开发库升级前已生成 `.local/backups/m2-before-v5-1795603845078.dump`，并用 pg_restore 列出备份目录验证可读；这不替代完整恢复演练。升级后保留账号 1、任务 16、授权历史 5，班级／课程原本均为空。未创建开发演示数据。

## 接口

统一前缀 `/api/v1/question-banks`，要求已登录的管理员／教师及 `questions.use` 权限，且已完成强制改密。

| 路径                            | 方法        | 用途                       |
| ------------------------------- | ----------- | -------------------------- |
| `/courses`                      | GET         | 分页查询有权选择的启用课程 |
| `/`                             | GET / POST  | 题库列表／创建             |
| `/:bank`                        | GET / PATCH | 题库详情／编辑与归档       |
| `/:bank/questions`              | GET / POST  | 题目摘要列表／录入         |
| `/:bank/questions/:id`          | GET / PATCH | 当前详情／保存新版本       |
| `/:bank/questions/:id/versions` | GET         | 历史分页，含教师可见答案   |
| `/:bank/questions/:id/archive`  | POST        | 按 revision 归档／恢复     |

分页最多 100 条。列表摘要不含答案、解析；有权访问的详情与历史接口才返回内容。错误沿用 `{code,message,requestId}`。审计仅保存题库、题目、版本 ID、题型和状态，不复制题干、答案或解析。未激活不妨碍题库维护，后续发布与入场再执行软件授权规则。

## 验收与后续

1. 创建课程与教师授课关系，管理员新建公共题库，录入五类题目并预览。
2. 编辑后查看 V1 和 V2，确认旧版未变；两个窗口编辑同一 revision 时仅一个成功。
3. 归档题目不能编辑，恢复后可编辑；归档题库保留全部历史。
4. 教师只能查看任课课程公共题库并维护个人题库；其他教师、跨课程和学生访问被拒绝。
5. 检查必填、错误答案、空位不匹配、筛选、权限变化、失败重试和移动端布局。

`test:questions` 使用独立测试库，覆盖 V4 升级、V5 失败回滚／重试、五题型校验、答案隔离、并发编辑、历史不可变、运行身份 DML、重启和真实浏览器流程。截图及结果在 `artifacts/m2-questions`。原 `test:m1`、`test:management`、`test:integration`、`test:ui` 和本地授权单元测试继续回归。

新版内部包须独立环境复验净机离线安装、已有 V4 数据维护升级、运行账户权限、ACL、HTTPS 与系统重启。M0／M1 第一批既有验收保留；M1 第二批及本批没有新增的独立环境验收结论。开发机不注册服务、不改防火墙、不重启系统。

后续顺序：固定模板导入与预检／图片附件 → 手动和条件组卷／冻结版本 → 授权控制的考试发布与考生名单 → 作答、保存和评分。完整 M2 完成标志仍是“可发布受授权控制的考试”，本批仅完成题库基础。
