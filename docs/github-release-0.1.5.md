## 云端验证

最终运行实际记录了以下测试输出及 `CI_VERIFICATION_COMPLETE`，不是仅根据步骤退出码判定通过：

- 同一 Windows 用户的真实受限令牌：非管理员角色，管理员专用文件读取被拒绝。
- 集成：重复迁移、任务幂等和崩溃领取、API 重启保留任务、本地授权导入及重启验签、无效授权保留原值、数据库不可用返回 503、关闭 Electron 后后台继续运行。
- 签发器：密钥库、序号、重复确认、日期边界、备份恢复、重启、信任配置；真实 Electron 解锁、签发、导出、受限 IPC、锁屏及空闲锁定、窄窗口。
- 客户兼容：供应方签发授权通过真实客户维护操作导入，使用真实 Windows 指纹，数据库连接重启后仍可验签。
- 自签名：固定指纹、文件篡改拒绝、缺少配置拒绝；独立 CI 回归覆盖 Secrets 缺失、PFX 错误口令及错误证书。
- 客户成品：隔离数据库冒烟、真实打包管理器诊断与导出、离线和 503、脱敏、拒绝覆盖及非法 frame。
- 签发器成品：从原 EXE 安装后执行真实 Electron 完整操作回归。
- 发布规则：版本不匹配、已发布标签、草稿提交不符及来源不符拒绝；上传后逐项下载核对资产字节。

初次验证器曾在未实际运行完整测试的情况下返回成功。发现后立即将预发行退回草稿，保留原资产，增加完成标记与真实子进程失败回归。修正受限令牌默认 DACL、独立桌面、工作区权限及标准句柄后，以上最终运行完整通过，才恢复公开发布。原始运行的绿色验证步骤不能作为验收证据。
