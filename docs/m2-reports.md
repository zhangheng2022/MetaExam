# M2 第七批：成绩统计与 Excel 导出

日期：2026-11-26。交付“成绩发布 → 全场／逐题统计 → 搜索筛选名单 → 下载 Excel”。数据库保持 V10，无新增迁移或历史数据修改；不改变评分规则、成绩发布不可变约束及学生本人查分接口。

## 范围与统计口径

- 只读取已发布成绩。教师只能访问本人且仍有有效授课关系的考试，管理员可管理全部；学生不能读取统计或导出他人成绩。权限来自当前认证身份，未激活软件不阻止查分与统计。
- 名单人数为考试发布时固定名单；实考为已交卷且完整评分的答卷，缺考不等于零分。用户名和姓名沿用名单快照，修改当前账号不改变历史名单；课程名称沿用现有考试接口的当前课程名称。
- 平均分、中位数、最高／最低分、合格人数、合格率和分布只统计实考，包含实考零分。无人实考时均分、中位数、最高／最低分、合格率为 null，页面显示“—”。合格人数与区间人数为 0。
- 合格比例默认 60%，允许 0～100 的整数，仅作本次分析，不设置正式及格线。合格条件使用半分整数单位比较，不以四舍五入后的得分判断。均分、中位数和比率最多保留两位小数。
- 分布按满分比例分为 [0,20)、[20,40)、[40,60)、[60,80)、[80,100] 五段。每段比例以实考人数为分母。
- 逐题展示题号、冻结题型、满分、评分人数、均分、得分率、满分人数及零分人数；无评分时均分和得分率为 null。不输出题干、标准答案、解析、学生原始作答、评语或评分人身份。
- 姓名／用户名搜索忽略大小写，支持全部／合格／不合格／缺考和用户名／总分升降序。总分排序始终将缺考置后，同分按用户名、账号 UUID 稳定排序。
- 搜索及状态筛选只影响名单，不改变全场及逐题统计。合格比例影响全场合格指标和名单合格状态。分页每页最多 100 条，导出全部匹配记录而非当前页。

本批不实现班级历史比较、跨考试分析、排名、正式及格线配置、成绩改动／撤回、CSV、补考或导出文件长期管理。当前名单没有逐考生的班级历史快照，不使用学生当前班级伪造历史统计。

## Excel 与运行约束

工作簿包含“统计概览”“成绩名单”“逐题统计”三张表。概览记录生成时间、发布时间、合格比例、搜索条件、名单筛选与排序、全场指标和分布；明确另外两表各自的统计范围。成绩名单记录用户名、姓名、状态、总分、满分及北京时间交卷时间；缺考成绩与时间留空。日期均标明北京时间。

沿用锁定的 ExcelJS 和现有文件处理 worker thread，不阻塞 API 主线程生成文件。单份最多 5000 名考生、200 道题；线程超时 15 秒、old-generation 内存上限 192 MiB。每个 API 进程最多同时生成两份，每账号最多一份，超限返回 429；该并发限制不是跨进程分布式限流。工作簿按需在内存生成，不保存到静态目录，不产生匿名下载链接。

用户名、姓名等写为原始字符串单元格，保留前导零及以 `=` 等开头的文本，不构造公式或超链接对象；成绩保持数值。文件名使用固定前缀及已验证的考试 UUID，不使用用户输入。响应设置 attachment 与 no-store。

生成前校验考试访问权及发布状态，生成完成后在统一业务锁内重新校验当前权限，再记录 `results.export` 审计并返回文件。权限撤销、强制改密或数据库异常时不返回已生成内容。审计仅记录考试、行数、状态、排序及比例，不复制名单、搜索姓名或文件内容；成功事件代表生成并通过返回前校验，不证明用户设备最终接收成功。

## 接口

统一前缀 `/api/v1/reports/exams/:id`，复用 Cookie、CSRF、严格 Zod 参数校验与统一错误格式。

| 方法与路径     | 参数与结果                                                 |
| -------------- | ---------------------------------------------------------- |
| GET 根路径     | passPercent；全场统计、逐题统计及安全考试信息              |
| GET `/records` | passPercent、q、status、sort、page、pageSize；安全名单分页 |
| POST `/export` | passPercent、q、status、sort；XLSX 二进制，不接受页码      |

未发布返回 409，匿名 401，学生 403，范围外考试按既有机制 404，导出并发超限 429，数据库异常或发现不完整的已发布成绩返回 503。

## 人工验收

1. 运行 `./tools/run.ps1 dev`。按 [阅卷与发布](m2-grading.md) 完成真实考试和成绩发布；无需新迁移，不创建默认数据。
2. 教师从“考试管理 → 考试详情 → 阅卷与成绩 → 成绩统计与导出”进入。未发布时没有入口，直接请求统计也应被拒绝。
3. 核对名单、实考和缺考数量、均分、合格率、分布及逐题结果。特别检查零分参与均分，缺考不参与；全员缺考时不能显示虚假的 0 分均分。
4. 修改比例、搜索姓名、切换状态和排序后点击“应用筛选”。未应用前导出禁用。刷新页面保持已应用条件；名单过滤后全场统计保持全场口径。
5. 点击“导出 Excel”核对确认信息。下载后打开三张表，核对全部匹配记录而非当前页，检查前导零用户名、缺考空单元格、实际零分及纯文本姓名。无匹配结果时名单仅有表头，仍有全场统计。
6. 检查导出进行中防重复、429／网络失败后的重试、数据库断连时隐藏旧结果和禁用导出，以及恢复后的刷新。手机检查表单换行和表格内部滚动。
7. 学生直接访问该路由不能导出；其他教师不能读取；撤销授课后原教师失去访问。修改当前账号姓名不应改写发布名单中的姓名。
