## 使用与人工验收

开发库已备份并升级到 V7。重新运行 `./tools/run.ps1 dev`，使用管理员或具有有效授课关系的教师账号登录浏览器。已有课程、题库和题目可直接使用；空系统先在教学组织和题库页面录入真实数据，不自动生成演示账号或题目。

1. 进入“试卷管理”，新建试卷，填写名称、所属课程和说明。课程创建后不能更换。空卷可以保存，不能冻结。
2. 点击“手动选题”，选择同课程题库，搜索题干或筛选题型，跨页勾选题目，填写默认分值后加入。切换题库清空本次勾选；已经选入的题目不会再次出现。
3. 点击“按条件抽题”，指定题库、题型、可选难度／标签／知识点、题数和分值。先故意填超过可用数量，确认整批不加入；再使用可用数量重试。每个条件同时满足才可抽中。
4. 修改单题分值、上移／下移或移除，点击保存。未保存时不能继续选题、抽题、预览或冻结；返回列表有丢弃确认，浏览器关闭／刷新有提醒。通过其他站内导航离开不会自动保存，请先保存修改。
5. 预览完整题干、图片、选项、答案和解析。此为教师预览，不是可分发给学生的答题页。检查总分、题序和选入版本；选入后题库有新版本时，已选版本保持不变。
6. 冻结并确认提示。冻结后刷新页面、重启 API，题目、顺序、分值和冻结版本 ID 保持不变；编辑按钮消失。修改题库中的源题并重新预览，冻结卷仍显示旧内容及旧图片引用。
7. 点击“复制为新草稿”，填写新名称。新卷拥有新 ID、相同的选入版本和分值，记录来源冻结版本；编辑新卷不影响旧卷。归档的题目／题库仍能在冻结卷中预览，但新草稿必须移除或替换不可用题目才能保存／冻结。
8. 用两个窗口编辑同一草稿，第二次过期保存应提示冲突，不能覆盖首次保存。教师不能访问另一教师的试卷；撤销授课关系后不能继续访问。学生没有入口，直接访问接口拒绝，不能获得答案。

## 规则与权限

- 一卷最多 200 题，每次条件抽题最多 100 题；随机抽取不放回，排除该卷已选的题目，同一道题的不同版本也不能重复加入。
- 每题 0.5～1000 分且是 0.5 的倍数；数据库用整数半分单位，汇总不使用浮点累积。总分不要求等于 100 分。本批不设计选项／空位局部分值、负分、章节或题组。
- 手动选题保留列表返回的确切版本；抽题选择执行时的当前版本。移除旧题、再重新选入可采用最新版本，系统不静默升级题目。
- 管理员管理全部试卷；教师仅管理本人、且课程和班级启用并仍有授课关系的试卷。公共题库可读、个人题库按既有权限可读；只能加入同课程且未归档的题目。停用课程后管理员可读旧卷，不能编辑／复制。
- 每个试卷只冻结一次；冻结后不允许修改、删除或解冻。需要修订时复制成新的草稿，未来考试应明确引用冻结版本 ID。
- 保存、抽题、复制和冻结均在事务内重查身份／数据范围，沿用全局业务写锁和 CSRF；草稿用 revision 防止覆盖。重复冻结返回同一冻结版本，事务失败不留下半份快照。审计记录标识、数量和结果，不复制题干或答案。

## 数据与升级

V1～V6 SQL 字节及校验和保持不变，V7 新增 `papers`、`paper_draft_items`、`paper_versions`、`paper_version_items` 和 `papers.use` 权限。管理员、教师内置角色拥有该权限。Drizzle 声明同步更新，不使用 push。API／Worker 不自动迁移；数据库版本不符时就绪失败。

冻结快照保存试卷名称、说明、课程、总分、固定题目版本 ID、题序和分值。题干、答案、图片关系通过已有不可变 question_versions 引用；不随 questions.current_version 改变。SHA-256 摘要覆盖 schemaVersion=1、试卷 ID、课程 ID、名称、说明以及有序 `{position,versionId,scoreUnits}` 数组。这是内容清单摘要，不是授权签名或可抵御数据库管理员修改的证明。

数据库触发器验证冻结快照与草稿逐项一致，保护冻结后的主记录和明细；快照表禁止 UPDATE／DELETE，冻结后也不能追加明细。运行数据库角色仅有快照 SELECT／INSERT 和必要草稿读写权限，不能 DDL。新的安装维护授权逻辑复用 `grantRuntimeAccess`。

## 接口

统一前缀 `/api/v1/papers`，均要求业务会话、papers.use、管理员／教师角色且不处于强制改密状态。错误沿用 `{code,message,requestId}`。

| 方法与路径            | 用途                                                 |
| --------------------- | ---------------------------------------------------- |
| GET `/`               | 名称、课程、状态筛选及分页列表                       |
| POST `/`              | 新建草稿，201                                        |
| GET `/:id`            | 详情和选入版本内容，含教师答案                       |
| PATCH `/:id`          | 带 revision 整体保存草稿名称、说明及有序题目／分值   |
| GET `/:id/candidates` | 指定题库筛选候选题，排除已选题目                     |
| POST `/:id/draw`      | 带 revision 按条件随机追加；数量不足 409、无部分写入 |
| POST `/:id/freeze`    | 带 revision 冻结，返回固定版本 ID；重复请求幂等      |
| POST `/:id/copy`      | 从冻结卷复制新草稿，201；保留来源版本 ID             |
