# 客户 0.1.17 管理器交付与验收

日期：2026-11-27。供应方保持 0.1.6。仅改本地管理器布局、进程生命周期、相关提示与版本；业务 API、schema V10、迁移和锁定运行库不变。

## 使用方式

- 默认 760×560 精简总览，授权维护、备份恢复、诊断和运行详情按需展开。窄窗口保持正文可读并允许纵向滚动。
- 关闭窗口或点击“后台运行”进入系统托盘；双击托盘、菜单“打开管理器”或重复启动恢复原输入和展开状态。
- 托盘“退出管理器”真正结束管理器进程；API、Worker、PostgreSQL 继续独立运行。仅手动启动，不增加登录自启动。
- 需要提升权限、升级或修复前，先从托盘退出。普通实例存在时，再以管理员身份启动只提示退出后重试，不转交维护操作。
- 原生文件对话框期间不能隐藏；正在执行维护时可后台运行，但主动退出被拒绝。托盘不可用时保持窗口可见，关闭真正退出。

## 本机通过

- build、typecheck、lint（零警告）、format:check；Ant Design 6.7.2 本地 CLI 检查无问题。
- 31 项单元测试、test:ui、test:desktop、test:license-manager、test:backup、test:diagnostics。
- 真实 Electron 验证：默认、380×480 窄窗与 150% 内容缩放；加载/故障/未初始化/授权状态；受限 IPC；普通权限拒绝；关闭隐藏、真实第二进程恢复、表单/折叠状态保留；隐藏超过一个轮询周期无新状态请求、恢复立即刷新；维护期间退出拒绝；实际诊断导出 IPC 的原生文件选择防隐藏；托盘失败回退与正常退出后测试服务存活。
- 主进程发送固定的可见性布尔事件，preload 仅转交值和取消订阅函数，不暴露 Electron 事件对象。隐藏不清空维护预览，也不延长其原有有效期；真正退出清理预览。
- 单实例提升权限提示、托盘菜单/双击和 session-end 分支通过测试适配器触发；不是物理托盘操作、实际 UAC 或 Windows 关机验收。测试适配器仅位于 tests/fixtures，不进入安装包，不提供生产权限开关。
