## 使用与人工验收

开发库已从 V5 升到 V6。重新启动旧版 dev 后，管理员或有任课权限的教师进入“题库管理”；管理员维护公共题库，教师维护本人个人题库。开发启动仍使用 `./tools/run.ps1 dev`，后台 Worker 必须同时运行。

1. 进入有写权限的题库，点击“Excel 导入与记录”，下载模板。填写说明在第二张工作表；第一张工作表标题不能更改。
2. 录入单选、多选、判断、填空、简答各一题，上传 `.xlsx`。观察等待／正在预检变为预检完成；预览题干、答案和解析，确认后才新增题目。关闭窗口后后台继续，可重新打开记录。
3. 再次上传相同文件，默认跳过重复题；选择“保留为新题”则创建独立题目，不覆盖任何旧题。重复点击确认不会重复执行整批导入。
4. 制作含错误答案或公式的文件，报告定位 Excel 行，有错误时不可确认。修正文件后重新上传。文件损坏时显示处理失败，不产生题目。
5. 编辑题目上传 PNG/JPEG，填写图片说明并保存。预览新版本图片；下一版移除图片，历史版本仍能显示原图。学生和匿名用户不能读取图片。
6. 用另一教师验证不能看上传者的预检报告或尚未关联题目的图片。取消授课关系后，后续文件访问和排队写入均被拒绝。
7. 在独立测试数据上停 Worker 后上传，再启动 Worker，任务应恢复；等待预检时可刷新页面。检查手机端表格局部横向滚动、错误和重试提示。

## 模板规则与限制

- 每文件 2 MiB，最多 500 数据行（表头后最多 500 行，空白行跳过）；标准模板工作表名为“题目”，固定 17 列，表头在第 1 行。模板不包含自动入库的示例题。另支持下述固定 15 列文字题库格式。
- 题型写“单选／多选／判断／填空／简答”，难度 1～5。知识点和标签用 `|` 分隔，沿用每项最多 10 个等题目校验。
- 选择题选项 A～H 连续填写，单选答案如 `A`，多选如 `A|C`；至少两个选项，多选至少两个正确答案。
- 判断答案写“正确／错误”。简答填写参考答案。
- 填空题干使用 `[[blank]]`，答案为 JSON 二维数组，例如 `[["2","二"],["4"]]`；数组顺序对应空位。区分大小写、忽略首尾空白分别填“是／否”，保留候选答案的原始空白。
- 只接受文字和数字单元格；不执行公式，不支持超链接、合并单元格、隐藏数据行、宏、内嵌图片、对象或外部引用。
- ZIP 不解压到磁盘；限制 80 个条目、单条 8 MiB、实际展开合计 12 MiB，拒绝路径异常、重复条目、加密、DTD 和外部关系。处理线程限制 192 MiB V8 堆及 15 秒超时；这不是整个原生进程的绝对内存配额。
- 重复判定使用题型、题干、选项与答案／填空规则，忽略随机 UUID、解析、难度、标签、知识点。比较同库所有当前版本（含归档题）及本批前序行；确认执行时再次检查。修改选项顺序或答案文字可被视作不同题，不承诺语义去重。
- 预检有效期为上传后 24 小时。每账号滚动 24 小时最多成功上传 20 个工作簿、100 张图片；API 同时最多 2 个文件上传／模板生成操作。限额计数保存数据库，重启不清空。

### 固定 15 列文字题库

可直接上传包含以下列的 `.xlsx`，列名、顺序必须完全一致：

`题目ID、题目类型、题目难度、题目描述、选项A、选项B、选项C、选项D、选项E、选项F、正确答案、题目解析、关联知识点ID、课程ID、题库ID`。

- 工作表名称不限，表头位于第 1 行或完全空白首行后的第 2 行。整个工作簿只能匹配一张题目表，包括标准模板；多张匹配时拒绝，隐藏的题目表或表头也拒绝。
- 支持“单选文本题、多选文本题、判断题”，分别对应单选、多选、判断；选项 A～F 和答案沿用上述校验。题目描述对应题干，题目解析对应解析。
- 难度支持很容易＝1、容易＝2、中等＝3、困难＝4、很困难＝5，以及数字 1～5；空值或未知文字报错。
- 题目ID、关联知识点ID、课程ID、题库ID 必须为空。题目导入页面当前选择的题库，不按外部 ID 更新旧题或建立课程关系；知识点和标签为空。
- 原始 Excel 行号保留在预检报告中，例如第 2 行表头的第一道题显示为第 3 行。每文件最多 500 数据行，允许的空白首行和表头不占额度；其余文件安全限制完全相同。
- 允许 WPS 等工具在第 15 列之后留下仅含样式的空白单元格；这些列一旦含实际内容仍拒绝，不使用非空列数量代替列位置检查。
- 同样先预检再确认，重复题可跳过或保留，确认时重新校验权限并原子入库。数据库仍为 V10，无新增接口或依赖。

## 数据与后台执行

V1～V5 SQL 及校验和不变。V6 新增 `question_imports`、`question_import_rows`、`question_attachments`、`question_version_attachments`，扩展 jobs 类型为 `question.preflight` 和 `question.apply`。逐版本事务、咨询锁、校验和、就绪版本验证及显式维护迁移继续沿用。

上传文件先以临时文件原子重命名，再写入导入记录和任务；数据库失败删除本次文件。进程在两步之间崩溃可能留下孤立文件，本批不自动清理。Worker 领取后复核账号、题库写权限及有效租约；报告持久化。确认只排队，执行时在同一事务内写题目、版本、结果和审计；任一行失败整批回滚，租约可恢复重试。完成记录用于幂等，不依赖浏览器存活。每次导入为新题，不向旧题追加或覆盖版本。

权限写入与角色／授课管理共享事务咨询锁。报告只对上传者开放，即使同课程其他教师可读该题库，也不能获取预检答案。审计保存批次、题库 ID、数量和结果，不记录题干、答案、文件内容或密码。

## 图片与存储

仅 PNG/JPEG；上传原文件最多 2 MiB、800 万像素，拒绝动画。Sharp 检查实际格式、解码、按方向转换并重编码 PNG，不保留 EXIF 等元数据；输出最多 8 MiB。每题最多 6 张，保存非空图片说明。图片在题干之后显示，不支持任意 HTML、外链、内联富文本或答案区插图。

数据库保存 UUID、归属、SHA-256、尺寸及字节数；原始 Excel 和规范化图片位于 `config.home/files/imports`、`config.home/files/images`，文件名由服务器 UUID 决定。开发默认 `.local/files`，安装默认 `%ProgramData%\MetaExam\runtime\files`。不放在 Web 静态资源目录。读取通过业务 Cookie 和当前题库权限，响应 `no-store`，校验文件摘要；文件丢失或被篡改返回 503。

尚未关联的图片仅上传者能读；关联后遵循题库可读范围。关联表禁止 UPDATE／DELETE，运行角色只有 SELECT／INSERT；移除编辑内容中的图片只影响新版本。源文件、失败记录和未关联图片暂不自动清理；不能以“当前版本没引用”判断可删除文件。磁盘容量及安全回收进入后续维护工作。

备份时停止 API／Worker，**同时备份数据库、配置／授权和整个 home/files 目录**，保留 Windows ACL。只还原 SQL 无法恢复图片。卸载继续保留数据目录。安装版 runtime 继承原有 API／Worker 服务账户权限，真实账户写文件及普通用户不可直接读取须在独立环境复验。

## 接口

统一前缀 `/api/v1/question-banks/:bank`。沿用登录、强制改密、课程范围和 CSRF 限制；JSON 请求仍限 64 KiB，multipart 独立限制单文件、无额外字段及 part 数量。

| 方法与路径                     | 用途                                       |
| ------------------------------ | ------------------------------------------ |
| GET `/import-template`         | 下载空白模板及说明；需题库写权限           |
| POST `/imports`                | multipart 的 file 字段；返回 202 和批次 ID |
| GET `/imports`                 | 当前上传者的分页记录                       |
| GET `/imports/:id`             | 批次摘要和逐行报告分页                     |
| POST `/imports/:id/confirm`    | duplicatePolicy 为 skip 或 keep；返回 202  |
| POST `/attachments`            | 上传并规范化图片，返回 201                 |
| GET `/attachments/:id/content` | 当前题库权限及图片归属校验后读取 PNG       |
