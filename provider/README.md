# 供应方测试签发工具

日常签发现在使用独立桌面工具：根目录执行 `./tools/run.ps1 dev:issuer`，使用说明及交付范围见 [供应方签发器](../docs/provider-issuer.md)。`build.mjs` 仅负责独立供应方安装包；原脚本继续保留为内部测试工具，不升级为正式签发入口。

`test-license.mjs` 仅用于内部测试密钥生成和离线授权签发，命令见根目录 README 的“本地授权”。先构建共享包，再使用项目 `.tools/node/node.exe` 执行。

临时密钥写入忽略提交的 `.local/provider`；私钥只保留在供应方开发机，不进入 Git、客户包或授权申请。客户应用只需要可信公钥，并通过 Node.js crypto 在本地验签。Windows 打包按文件白名单复制产物，额外扫描私钥及签发工具；本目录不参与客户应用构建。

本工具及临时公钥不是正式发布密钥治理方案。
